# ADR-007 — ReportLab para Documentos desde Backend

| Campo | Valor |
|---|---|
| Estado | **APPROVED** |
| Fecha | 2026-08-03 |
| Decisión | Generación de PDF/reportes con ReportLab desde backend; el navegador no produce documentos fiscales definitivos |
| Fuente | DOC-08 (§16), DOC-01, DOC-03 (§14) |
| Ruta | `specs/001-fundacion/adr/ADR-007.md` |

## Contexto
Los documentos fiscales/empresariales deben ser reproducibles, auditables, con snapshot y hash; no deben depender del navegador para cálculos.

## Opciones
1. ReportLab backend (decisión).
2. Impresión HTML (descartado para documentos críticos).

## Ventajas
- Cálculos con datos snapshot del servidor.
- Hash, metadatos y auditoría.

## Consecuencias
- Infraestructura `ReportDocument`, `ReportHeader`, `ReportFooter`, `TableBuilder`, `MoneyFormatter`, `DateFormatter`, `CompanyBranding`, `AuditMetadata`, `QRBuilder`, `DocumentHash`.
- Plantillas versionadas con código y versión.
