# ADR-015 — Política de Modales

| Campo | Valor |
|---|---|
| Estado | PROPUESTO |
| Fecha | 2026-08-03 |
| Decisión | No usar modales para crear/editar entidades, matrices, DataTables, configuraciones extensas, documentos, permisos ni procesos complejos. Los formularios complejos usan ruta y pantalla completa. Los modales se reservan para confirmación breve |
| Fuente | DOC-08 (§7, FR-001/FR-002), DOC-04 (§28) |
| Ruta | `specs/001-fundacion/adr/ADR-015.md` |

## Contexto
INNOVA retrabajó por modales abusados. El Estándar prohíbe modales para formularios complejos.

## Opciones
1. Pantalla completa para procesos complejos (decisión).
2. Modales generalizados (descartado).

## Ventajas
- URL propia, breadcrumbs, contexto, validación completa y cambios sin guardar.
- Accesibilidad y responsive consistentes.

## Consecuencias
- Patrones WF-01..WF-09 en `wireframes/`.
- Modales solo para confirmar desactivar/eliminar/anular/reversar/descartar y alertas breves.
