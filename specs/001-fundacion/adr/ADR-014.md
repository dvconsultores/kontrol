# ADR-014 — Versionado de Dependencias

| Campo | Valor |
|---|---|
| Estado | PROPUESTO |
| Fecha | 2026-08-03 |
| Decisión | Versiones fijas en lockfiles e imágenes Docker; sin `latest` en producción; imágenes fijadas por digest cuando sea razonable; política de actualización controlada |
| Fuente | DOC-08 (§2, FR-037), Constitución P16 |
| Ruta | `specs/001-fundacion/adr/ADR-014.md` |

## Contexto
Las dependencias y las imágenes deben estar versionadas. No usar `latest` en producción.

## Opciones
1. Versiones fijas + lockfiles (decisión).
2. Rangos abiertos (descartado).

## Ventajas
- Builds reproducibles.
- Gestión de CVE controlada.

## Consecuencias
- `package-lock.json`/`pnpm-lock.yaml`, `requirements.lock`/`uv.lock`.
- Imágenes fijadas; fechas de actualización y CVE documentados.
- Actualizaciones mayores mediante Spec independiente.
