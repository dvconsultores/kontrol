# ADR-006 — Sistema de Diseño Compartido

| Campo | Valor |
|---|---|
| Estado | **APPROVED** |
| Fecha | 2026-08-03 |
| Decisión | Un sistema de diseño único y obligatorio (tokens + componentes compartidos) antes de construir módulos de negocio |
| Fuente | DOC-08 (§4, §20), Constitución P7/P17/P18 |
| Ruta | `specs/001-fundacion/adr/ADR-006.md` |

## Contexto
El retrabajo de INNOVA se originó en inconsistencias visuales por módulo. KONTROL no permite que cada equipo resuelva formularios, tablas, botones, loaders, mensajes, modales, validaciones, estados y errores de forma distinta.

## Opciones
1. Sistema de diseño único (decisión).
2. Estilos por módulo (descartado: retrabajo).

## Ventajas
- Consistencia global, accesibilidad y responsive centralizados.
- Componentes probados una sola vez.

## Consecuencias
- Tokens (color, tipografía Ubuntu, espaciado 4px, radios, sombras, z-index, tamaños, breakpoints).
- Lucide React como única librería de iconos.
- Documentación de componentes (catálogo/Storybook).
