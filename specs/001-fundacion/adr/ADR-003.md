# ADR-003 — PostgreSQL como Fuente de Verdad

| Campo | Valor |
|---|---|
| Estado | PROPUESTO |
| Fecha | 2026-08-03 |
| Decisión | PostgreSQL es la única fuente de verdad transaccional; Redis/caché nunca reemplaza datos permanentes |
| Fuente | DOC-03, DOC-05, DOC-08 (§2.1) |
| Ruta | `specs/001-fundacion/adr/ADR-003.md` |

## Contexto
Se requiere fuente única, constraints, locks, transacciones, auditoría y reconstrucción de saldos/libros desde eventos.

## Opciones
1. PostgreSQL (decisión).
2. Otra base relacional.
3. NoSQL como fuente primaria (descartado: integridad fiscal requiere transacciones y constraints).

## Ventajas
- Constraints e índices implementan reglas críticas.
- Transacciones atómicas y locks para numeración/control/stock.
- Reconstrucción de libros/saldos desde eventos.

## Consecuencias
- Versión propuesta PostgreSQL 18.x (validar en research; CL-11/CON-01).
- Migraciones Alembic revisadas; auditoría particionada.
