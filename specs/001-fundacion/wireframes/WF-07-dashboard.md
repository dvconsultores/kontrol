# WF-07 — Dashboard

Patrón de dashboard de inicio (DOC-04 pantalla 01).

```text
┌──────────────────────────────────────────────────────────────┐
│ Breadcrumbs · Dashboard                     [Filtros globales] │
├──────────────────────────────────────────────────────────────┤
│ KPI 1   KPI 2   KPI 3   KPI 4   (por rol, configurables)      │
├──────────────────────────────────────────────────────────────┤
│ Alertas accionables                                          │
├──────────────────────────────────────────────────────────────┤
│ Tablas cortas con enlaces a detalle · Moneda y período        │
└──────────────────────────────────────────────────────────────┘
```

Reglas: indicadores configurables por rol; alertas accionables, no solo informativas; moneda y período explícitos; accesible con resumen textual para gráficos.
