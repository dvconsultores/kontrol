SEPARADOR 07 — MANUAL TÉCNICO DEL FABRICANTE DE HARDWARE

Aplicabilidad del requisito de manual del fabricante (hardware) y matriz de equipos para KONTROL.

Aplicabilidad («según corresponda»)

La exigencia de entregar el Manual Técnico del Fabricante de hardware se aplica «según corresponda», es decir, cuando el sistema opera o se integra con hardware fiscal (impresora fiscal, máquina fiscal, POS fiscal, dispositivo fiscal, controlador o equipos homologados relacionados).

KONTROL, en su versión 1.0.0, es un sistema de software (SPA + API REST + base de datos) que no se integra actualmente con hardware fiscal. Por lo tanto, este separador documenta la aplicabilidad, declara que no existen equipos en la instalación de referencia y establece la matriz técnica que se completará por cada equipo homologado cuando KONTROL se integre con hardware fiscal.

1. Declaración de aplicabilidad

ÍtemRespuesta
¿KONTROL se integra con hardware fiscal en la versión 1.0.0?No. La generación de documentos es de software (emisión electrónica y control de numeración).
¿Existen impresoras, máquinas o dispositivos fiscales en la instalación de referencia?No.
¿Aplica la entrega de manual técnico de fabricante hoy?No aplica («según corresponda»). Este separador queda como declaración y matriz preparada.

2. Relación prevista de KONTROL con hardware fiscal

Si en una instalación futura KONTROL se integra con equipos homologados (impresión fiscal, máquina/POS fiscal o dispositivo de control fiscal), la integración se documentará en el expediente mediante la siguiente matriz, y se adjuntará el manual técnico oficial de cada fabricante. KONTROL contempla en su núcleo fiscal el registro de números de control de imprenta autorizada (lotes con impresora asociada y estado individual de cada número), que es la base de datos que alimentará la impresión fiscal homologada.

3. Matriz por equipo homologado

Por cada equipo se completarán los siguientes campos en el expediente (esta matriz se diligencia cuando exista integración):

Actualización del expediente

Cuando KONTROL se integre con un equipo homologado en una instalación concreta, este separador se actualizará con la matriz diligenciada y se adjuntará el manual técnico oficial del fabricante correspondiente, en cumplimiento de la exigencia «según corresponda».
